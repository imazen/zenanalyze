# imazen-26 HDR renditions + HDR features (2026-06-14)

Real HDR for the corpus — correcting an earlier wrong call that the heic/UltraHDR
were SDR (that was a flawed probe: `gainmap_inspect` only walks ISO-21496 and
missed Apple maker-headroom/tmap; PIL truncated 16-bit reads). The proven
`~/work/hdr-corpus-convert` (HEIC/UltraHDR → `GainMapRender::ReconstructHdr` via
the heic/zenjpeg zencodec adapters → 16-bit PQ) was used; features then extracted
through the generic bit-depth/transfer-aware `analyze_features` depth tier.

## Renditions — `/mnt/v/output/imazen-26-hdr-2026-06-14/`

`hdr-corpus-convert <out> ~/work/codec-corpus/imazen-26` → **2563 `.sdr.png`
(display SDR) + 76 16-bit PQ `.hdr.png`**, 0 failed. The 76 HDR sources are the
gain-map/Apple-headroom phone shots, all in the lilith photo classes
(`1400-nature` 47, `1200-interiors` 20, `1000-general` 6, `1600-food` 3) — i.e.
genuine HDR is ~76 sources, concentrated in photos (not most of the corpus).
Renditions regenerate from the convert; not Tower-mirrored.

## HDR features (canonical)

`/mnt/v/output/imazen-26-features/imazen26_hdr_features_2026-06-14.parquet` —
**76 rows × 116 cols** (6 meta + 110 features), sha256-16 `9677f3da622b7e5f`,
Tower-mirrored. Schema adds `primaries` / `transfer` (cICP codes) to the feature
columns. Extractor: `examples/extract_hdr_features.rs` — parses each PNG's `cICP`
(primaries 33×BT.709 / 43×Display-P3, transfer all PQ), decodes 16-bit RGB
(native-endian u16), wraps a u16 `PixelDescriptor::RGB16.with_transfer(Pq)
.with_primaries(..)` `PixelSlice`, runs `analyze_features` (`experimental,hdr`).

**Depth tier verified live** (dead in the SDR set): peak luminance **379–1646
nits** (median 620), p99 82–1267, headroom **2.2–4.4 stops** (median 2.95),
hdr_pixel_fraction 0.01–0.60, effective_bit_depth 14, `hdr_present` = true for
all 76.

## Regenerate

```bash
~/work/hdr-corpus-convert/target/release/convert \
  /mnt/v/output/imazen-26-hdr-<DATE> ~/work/codec-corpus/imazen-26
cargo run --release --features experimental,hdr --example extract_hdr_features -- \
  --hdr-dir /mnt/v/output/imazen-26-hdr-<DATE> \
  --out     /mnt/v/output/imazen-26-features/imazen26_hdr_features_<DATE>.tsv
```
