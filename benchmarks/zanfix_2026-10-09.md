## Scalar-tier speed (`cargo bench --bench tier_isolation --features _dev`, zenbench)

| image | v3 main → fixed | scalar main → fixed |
|---|---|---|
| 512² | 4.2 → 4.2 ms | 6.7 → 23.1 ms (3.4×) |
| 2048² | 11.2 → 10.8 ms | 16.4 → 46.0 ms (2.8×) |

The scalar cost is magetypes' correctly rounded software FMA (`fmaf_soft`) on every multiply-add.
A branchless variant was 10–13 % faster (20.1 / 41.3 ms). That isn't enough to justify a second
implementation, so the kernels call magetypes' own routine.
